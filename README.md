# Sales Prediction Using Machine Learning

#Project Overview
This project predicts sales based on advertising expenditure on TV, Radio, and Newspaper using Linear Regression.

#Objectives
- Analyze advertising expenditure and sales.
- Perform data visualization and analysis.
- Build a machine learning model to predict sales.
- Evaluate model performance.

#Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook

#Project Files
- `Sales_Prediction.ipynb` – Project code and analysis
- `advertising.csv` – Dataset
- `requirements.txt` – Required Python libraries

#Model Evaluation
The model can be evaluated using MAE, MSE, RMSE, and R² score.
